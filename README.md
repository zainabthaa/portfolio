# Zainab Taha — Cybersecurity Portfolio

Personal portfolio covering GRC, network & cloud security, and security operations projects.

**Live site:** https://zainabthaa.github.io/portfolio/

Plain HTML/CSS/JS, no build step. Hosted on GitHub Pages from the `main` branch root.

## Updating

- Content lives in `index.html`; images in `assets/img/` (WebP, max 1600px wide). fixing
- Capstone screenshots: add `assets/img/lml-soc.webp` and `assets/img/lml-grc.webp`, then uncomment the block marked `CAPSTONE SCREENSHOTS` in `index.html`.
