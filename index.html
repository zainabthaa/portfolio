Compliance-as-Code Policy Enforcement Pipeline

Catches insecure AWS infrastructure in the pull request, before it can be merged or deployed.

  • Built a GitHub Actions pipeline that runs terraform plan, checks the plan with OPA/Rego + Conftest, and blocks non-compliant pull requests through branch protection.
  • Codified 7 CIS AWS Foundations Benchmark controls + 3 custom checks across 6 policy modules: S3, RDS, security groups, IAM, EBS and hard-coded secrets.

Secure Banking System

A desktop banking app in Java and Swing, built with security and testability from the start.

  • PINs and admin password hashed with PBKDF2-HMAC-SHA256 (600,000 iterations, per-record salt), compared in constant time, and wiped from memory after use.
  • Accounts lock after 3 wrong PINs, and the counter survives restarts. Errors are generic, so account numbers can't be enumerated.
  • Layered architecture with repository interfaces, atomic file writes and BigDecimal money maths.
  • 62 JUnit 5 tests, with CI on Linux, Windows and macOS through GitHub Actions.
