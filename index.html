Secure Banking System

A desktop banking app in Java and Swing, built with security and testability from the start.

600kPBKDF2 iterations per hash
62JUnit 5 tests
3operating systems in CI
JavaSwingPBKDF2JUnit 5GitHub Actions
Code
  • PINs and the admin password are hashed with PBKDF2-HMAC-SHA256 (600,000 iterations, per-record salt), compared in constant time, and wiped from memory after use.
  • Accounts lock after 3 wrong PINs, and the counter survives restarts. Errors are generic, so account numbers can't be enumerated.

Published research

Peer-reviewed work on AI-based intrusion detection for critical energy infrastructure.

Peer-reviewed Journal article Published 13 Oct 2026

AI-Powered Intrusion Detection for Programmable Logic Controllers in Smart Grid and Industrial Energy Networks: A Reproducible Docker-Based Simulation Platform

Natali Soukh, Zainab Taha, Passent Elkafrawy

Intelligent Computing for Energy and Environment (ICEE) · Vol. 1, No. 1 · 2026

Energy-sector OT networks increasingly connect to corporate IT, which exposes legacy control systems to new attacks. Commercial OT monitoring tools are closed and expensive, so we built an open, fully containerised IT/OT testbed. It generates its own labelled traffic, trains a Random Forest on flow features, and detects a two-stage attack (reconnaissance, then exfiltration) live on a Streamlit dashboard.

22flow-level features
4+MLthreshold rules + Random Forest layer
5-foldcross-validated on the generated dataset
Key finding

Normal and attack flows separated completely in this synthetic setting: normal traffic scored 0.000–0.015 attack probability and attack traffic scored 0.950–1.000. Cross-subnet traversal, flow duration and TCP SYN count were among the strongest signals. Next, the platform will be extended to native PLC protocols (Modbus, DNP3) and validated against public benchmarks.
